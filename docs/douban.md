# 豆瓣书影音

入口为 `/life/douban`。每位网站用户自行填写豆瓣个人主页或主页 ID，连接、收藏资料、同步进度及导入回执均按当前网站账户隔离。主页由用户声明关联，不代表网站已完成豆瓣身份验证。网站不接收豆瓣密码或 Cookie。

## 本机浏览器扩展同步

桌面 Chrome／Edge 用户可从书影音页下载同步扩展，解压后在浏览器扩展管理页启用开发者模式、加载该文件夹。随后必须在安装了扩展的同一个浏览器中打开本站，点击“登录豆瓣”在豆瓣自己的页面完成登录，再回本站点击“通过浏览器同步”。这是本机扩展，不能在 ChatGPT／Codex 的内置浏览器、Safari 或手机中直接调用。

登录 Cookie 由浏览器和豆瓣正常管理，扩展不读取 Cookie 原文、不获取密码、不将登录凭据上传服务器，也不另存一份登录凭据。退出豆瓣、清除 Cookie 或会话过期后需要重新登录。网站检测到扩展可连接不代表已验证豆瓣登录；实际读取时会核对页面、绑定主页及可用的账户证明，无法证明时不宣称完成身份验证。

1.0.1 起兼容登录后的“个人主页” `/mine/` 导航入口；此跳转链接不包含账户 ID，因此不会将它误当异常，也不把它作为账户身份已验证的证据。明确指向其他账户的主页链接仍会停止同步。同步失败时可区分列表标题、收藏数量、条目链接、分页或脚本加载等原因，诊断不包含原始网页、链接或异常内容。

更新本机扩展需重新下载 ZIP、覆盖原目录，并在浏览器扩展管理页点击重新加载，再刷新本站。网站会显示检测到的扩展版本，并阻止已知不兼容的旧版继续读取。

打开网站、检测扩展、创建同步进度均不读取收藏；用户点击同步后，扩展从本机网络读取已完成影视、图书及音乐列表，每步最多一页，步骤之间至少间隔 1.5 秒。扩展只向发起操作的本站标签页返回规范化条目和来源进度，不传原始 HTML、密码、Cookie 或验证页。登录、验证、访问拒绝和限流会明确停止对应读取，不自动处理验证。站点服务器上的公开读取仍可单独使用，其出站限制不会因此被视为已解除。

网站将每页条目按当前网站账户保存，每次最多推进二十步，可暂停、继续；暂停会先完成当前页的保存。网络中断后，扩展重放同一步的原结果、本站重试同一保存回执，成功保存后才进入下一页。账户变化会取消读取并丢弃旧操作后续返回。已知主页改绑会停止继续读取；原来源已有的待确认保存，仅在同一网站账户下核对原提交，不能当成新来源的数据。

扩展无需 Cookie 或持久存储权限，只使用 tabs／scripting 及三个固定豆瓣来源域名权限。外部命令限制为指定生产站点的书影音页，并绑定网站标签页、当前操作标识及来源主页；原始条目仅在当前操作内存中暂存。页面刷新或扩展后台重启后，未完成部分可能需要重新读取；已保存条目保留且按来源域与条目 ID 去重，不将重启后的空进度误报为完整同步。

扩展包从公开源文件生成，生产构建和 CI 验证下载 ZIP 与实际 worker／解析脚本一致。测试使用合成页面和登录状态，不接触用户真实 Cookie。

## 公开同步

保存连接只保存配置；点击“同步公开记录”才读取豆瓣。按影视、书籍、音乐三个公开收藏来源分页读取完成标记，并保存个人评分、标记日期、短评及可用封面。电影和电视剧共用豆瓣影视收藏来源，依据条目明确元数据识别；无法核实的显示为“待分类影视”，不按名称猜测类型。

每个服务器步骤最多一次外部请求。页面每次最多执行二十步，步骤间留有间隔，可暂停并在下次手动继续；打开页面或刷新不会自动联网续传。游标及配置／运行版本存于服务器，旧页面或改绑后的旧运行不能将结果写入新绑定。断开和改绑不删除已有资料，列表可查看全部已保存来源或当前绑定来源。

遇登录页、验证码、安全验证、403、418、限流、异常内容或分页不一致时，来源显示为受限／失败，不当成空收藏。可访问来源仍可继续。官方 RSS 仅补充有限的近期完成动态，不能补齐历史全量；未完成的“在看／在读”等状态不进入完成收藏。RSS 发布时间单独保存，不能代替豆瓣标记日期。

各来源分别显示超时、连接失败、豆瓣拒绝读取、登录要求或安全验证等具体原因。网站登录不会为服务器建立豆瓣登录会话；在本人浏览器可见的收藏仍可能拒绝服务器匿名读取。来源卡片提供对应收藏页和导入入口，可在本人浏览器保存收藏 HTML 后补齐。该入口只准备导入选项，不自动打开豆瓣、读取文件或提交资料；已有导入草稿及待确认回执会保留。

运行结果区分完整完成、部分完成、失败和仍在运行。完整完成仅表示本次可访问的公开收藏分页与公开影视类型核对已完成，不保证获得私密记录，也不把抓取缺席当作删除。个人评分与条目站点评分分开，音乐条目不是播放器的播放历史。

## 私密资料导入

用户在本人豆瓣账号登录后保存收藏页面，或选择自己已有的 JSON、CSV、Obsidian 豆瓣插件 Markdown 导出资料。支持字段、示例和限制见 [导入说明](douban-import.md)。没有完成状态的资料需要用户明确确认完成；已有的想看／在看／想读／在读等标记不会因此变为完成记录。

文件只在本机内存中解析，不上传原始网页、文件名或额外元数据，也不把文件内容发送给豆瓣或 AI。HTML 在未插入页面的惰性模板中解析，节点不会执行脚本或加载图片、iframe 等外部资源。导入时不会自动查询条目详情。

本地解析后，网站只接收规范化的记录用于预览，展示新增／更新／未变化数量。用户核对后点击“确认导入”才原子保存。预览绑定当前用户、来源主页、记录内容及受影响的已有业务值；预览后内容发生变化会要求重新核对，不能静默覆盖。网络回执不明时只能显式重试原操作标识与内容，避免重复导入。

导入不要求已绑定公开连接，也不改变连接。导入资料中的已知个人字段不会被后续公开同步擦除；再次明确导入可更新这些资料。导入表单和待确认内容仅留当前页面，账号切换后旧页面不能向新账号提交。

## 封面与影视分类

所有类别及来源都显示封面图，包括私密导入。已有官方封面通过本站登录后的图片代理读取，不由浏览器直连第三方；代理只接受当前账户已保存的条目键，不接受任意图片 URL。缺失、不可用或被拒绝的封面显示明确标注“暂无封面”的本地图，不将占位图当作官方封面。

“补全本页封面与分类”只在用户主动点击后逐条查询当前页条目的公开详情，步骤之间留有间隔，并可暂停；包括用户明确选择补全的私密导入条目。请求只带条目类型和 ID，不向豆瓣发送个人评分、短评或标记日期。来源受限会保留已有字段；限流会停止后续请求，不自动循环重试。

影视识别优先采用明确的电视剧类型、集数和单集片长，避免把豆瓣通用的 Movie 标记直接当成电影结论。电影需有相互印证的类型和页面信息，不能确认时保留“待分类影视”。详情中可手动纠正为电影或电视剧；手动选择会优先保留，自动补全、公开同步及后续导入不会将其覆盖。已明确分类的导入资料也不会被自动详情查询擅自更改。

## 在本人浏览器导出书籍

服务器的图书公开读取可能被豆瓣拒绝，即使本人浏览器登录后可查看收藏。图书来源卡片提供绑定该主页的“在本人浏览器导出书籍”书签助手：将入口拖到桌面浏览器书签栏，打开对应的豆瓣“读过的书”列表，点击该书签，再明确选择读取当前页或逐页读取。

助手仅在绑定主页的 HTTPS 图书收藏路径运行，使用当前浏览器正常的同源登录状态，不读取或导出密码、Cookie。每页读取留有间隔；遇到登录、验证、拒绝访问、限流、分页异常或取消时停止，并保留已读取部分供用户下载。单批最多 500 条、40 页，继续位置会明确显示，不能将受限或分批结果当作历史全量。用户点击下载后只生成本机 JSON，需返回本站预览、确认导入才会保存；助手不自动向本站上传资料。

## 存储与备份

迁移 `0024_douban` 新增连接、条目、同步运行及导入回执四张表。收藏唯一键包含当前用户、来源主页、来源域及条目 ID，影视分类升级不会重复创建同一条目。

收藏条目纳入业务备份；连接、同步控制字段及操作回执不随业务备份携带，恢复不会绑定主页或自动联网。新备份包含三十一类业务表，并保持既有三十表、二十七表分卷签名及历史 v1/v2 文件兼容。只有观察时间推进不算业务内容冲突，个人评分、短评等真正变化仍须核对。
