# 导入本人私密书影音记录

私密记录需要在本人已登录豆瓣的浏览器或本地工具中导出。本站不获取豆瓣密码、Cookie 或访问令牌，也不声称完成了豆瓣账号所有权验证。导入时填写的主页是这批资料的来源归属；不自动改绑公开同步主页。

选择文件后，浏览器在本机读取并解析文本。原始 HTML、Markdown、CSV、JSON 文件不上传；点击“预览导入”后，仅规范化条目发送给本站核对已有资料，预览不保存；点击“确认导入”后才写入收藏。浏览器HTML解析使用未插入页面的 template.content，不使用可能加载图片的原生DOMParser；不执行脚本或加载图片、iframe、CSS等资源。解析不访问豆瓣或AI。

一次最多选择100个文本文件，合计8 MiB，最多500条输入记录。单份HTML最多2 MiB、30条列表记录。超过时请分批导入；JSON和CSV使用UTF-8编码。预览会说明跳过的未完成状态和合并的重复项，格式损坏会拒绝整个预览，不静默保存前面已经读到的部分。

## 已登录后保存豆瓣网页

1. 在本人浏览器登录豆瓣，进入自己的“看过”“读过”或“听过”收藏列表。
2. 按浏览器“保存网页”保存当前列表页面的 `.html` 文件。只选择保存的HTML文件，不需要选择旁边的图片资源文件夹。
3. 如果有多页收藏，逐页保存并一起选择。一个保存页只代表这一页，不能视为历史全量。
4. 在本站填写与保存页一致的豆瓣主页ID，选择文件并预览。明确来源主页不一致、验证页面、想看／在看页面及条目详情页不会当作已完成收藏导入。

网页中没有可靠电影／电视剧类型时，影视记录先保留为“待分类影视”。保存网页被浏览器改写为本地路径的封面会留空；不会上传或读取本地图片。

## Obsidian 豆瓣笔记

兼容 [obsidian-douban](https://github.com/Wanxp/obsidian-douban) 常见导出字段：`doubanId`、`title`、`type`、`url`、`state`、`myRating`、`collectionDate`，以及 `Comment:` 段落中的个人短评。这是对文件格式的兼容，不执行或复制插件的登录、同步和验证代码。

应在插件中导出包含个人状态的笔记；支持“看过／读过／听过”或 `collect` 等完成状态。只有文件没有状态字段时，才可由用户勾选“这些条目均已完成”进行声明；已经注明的想看、在看、想读、在读等非完成状态仍会跳过。未知的非空状态也不会被猜作完成。

Markdown仅解析有限的简单顶部字段和普通文字，不执行完整YAML语法。脚本标签、锚点和引用会被拒绝。登录凭据字段会被拒绝；与收藏无关的导出字段不进入规范化结果。

## CSV 和 JSON

CSV的推荐列为：

```csv
title,url,type,state,myRating,collectionDate,myComment
我的电影记录,https://movie.douban.com/subject/1234567/,movie,看过,4,2026-11-12,自己的短评
```

类型支持 `movie`、`series`、`screen`、`book`、`music`，也支持常见中文名称。`screen` 表示尚不能确认是电影还是电视剧。可不填类型，由条目链接确定影视／书籍／音乐；影视不会按片名猜细分类。

JSON可使用同样字段的数组：

```json
[
  {
    "title": "我的书籍记录",
    "url": "https://book.douban.com/subject/2345678/",
    "type": "book",
    "state": "读过",
    "myRating": 5,
    "collectionDate": "2026-11-12",
    "myComment": "自己的阅读短评"
  }
]
```

个人评分读取 `myRating`、`personalRating`、`userRating` 或“个人评分”，范围1–5星；未评分留空或 `null`。普通文件中的 `score`、`rating` 或“豆瓣评分”可能是站点评分，故不当作个人评分。需要采用本站规范的 `rating` 字段时，使用显式清单 `{"format":"jiashu-douban-import-v1","items":[...]}`，仍需每条完成状态或用户对缺失状态的明确确认。

标记日期读取 `markedDate`、`myCollectionDate`、`collectionDate` 或“标记日期”，不拿出版日期或文件创建时间代替。评分、标记日期和短评可以未知；不把未知填成0。所有条目链接需为豆瓣电影、书籍或音乐条目的规范链接。

同一来源主页中按“来源域＋条目ID”去重。相同条目内容完全相同会合并；不同文件给出冲突评分、短评或其他内容时，会要求先保留正确的一份再预览，避免静默覆盖。
