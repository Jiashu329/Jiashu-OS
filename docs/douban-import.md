# 导入本人私密书影音记录

私密记录需要在本人已登录豆瓣的浏览器或本地工具中导出。本站不获取豆瓣密码、Cookie 或访问令牌，也不声称完成了豆瓣账号所有权验证。导入时填写的主页是这批资料的来源归属；不自动改绑公开同步主页。

选择文件后，浏览器在本机读取并解析文本。原始 HTML、Markdown、CSV、JSON 文件不上传；点击“预览导入”后，仅规范化条目发送给本站核对已有资料，预览不保存；点击“确认导入”后才写入收藏。浏览器HTML解析使用未插入页面的 template.content，不使用可能加载图片的原生DOMParser；不执行脚本或加载图片、iframe、CSS等资源。解析不访问豆瓣或AI。

一次最多选择100个文本文件，合计8 MiB，最多500条输入记录。单份HTML最多2 MiB、30条列表记录。超过时请分批导入；JSON和CSV使用UTF-8编码。预览会说明跳过的未完成状态和合并的重复项，格式损坏会拒绝整个预览，不静默保存前面已经读到的部分。

## 已登录后保存豆瓣网页

图书也可使用来源卡片里的“在本人浏览器导出书籍”助手：将入口拖到桌面浏览器书签栏，在对应主页的豆瓣“读过的书”列表运行，主动读取后下载 JSON，再回本站选择文件。助手支持有间隔地逐页读取；遇到限制会保留已读部分，超过单批范围需按提示继续下一段。它不读取或上传豆瓣密码、Cookie，也不会自动把文件提交本站。

1. 在本人浏览器登录豆瓣，进入自己的“看过”“读过”或“听过”收藏列表。
2. 按浏览器“保存网页”保存当前列表页面的 `.html` 文件。只选择保存的HTML文件，不需要选择旁边的图片资源文件夹。
3. 如果有多页收藏，逐页保存并一起选择。一个保存页只代表这一页，不能视为历史全量。
4. 在本站填写与保存页一致的豆瓣主页ID，选择文件并预览。明确来源主页不一致、验证页面、想看／在看页面及条目详情页不会当作已完成收藏导入。

网页中没有可靠电影／电视剧类型时，影视记录先保留为“待分类影视”。保存网页被浏览器改写为本地路径的封面会留空；不会上传或读取本地图片。

## Obsidian 豆瓣笔记

兼容 [obsidian-douban](https://github.com/Wanxp/obsidian-douban) 常见导出字段：`doubanId`、`title`、`type`、`url`、`state`、`myRating`、`collectionDate`，以及 `Comment:` 段落中的个人短评。这是对文件格式的兼容，不执行或复制插件的登录、同步和验证代码。

应在插件中导出包含个人状态的笔记；支持“看过／读过／听过”或 `collect` 等完成状态。只有文件没有状态字段时，才可由用户勾选“这些条目均已完成”进行声明；已经注明的想看、在看、想读、在读等非完成状态仍会跳过。未知的非空状态也不会被猜作完成。

Markdown仅解析有限的简单顶部字段和普通文字，不执行完整YAML语法。脚本标签、锚点和引用会被拒绝。登录凭据字段会被拒绝；与收藏无关的导出字段不进入规范化结果。

## CSV 和 JSON

CSV的推荐列为：

```csv
title,url,type,state,myRating,collectionDate,myComment
我的电影记录,https://movie.douban.com/subject/1234567/,movie,看过,4,2026-11-12,自己的短评
```

类型支持 `movie`、`series`、`screen`、`book`、`music`，也支持常见中文名称。`screen` 表示尚不能确认是电影还是电视剧。可不填类型，由条目链接确定影视／书籍／音乐；影视不会按片名猜细分类。

JSON可使用同样字段的数组：

```json
[
  {
    "title": "我的书籍记录",
    "url": "https://book.douban.com/subject/2345678/",
    "type": "book",
    "state": "读过",
    "myRating": 5,
    "collectionDate": "2026-11-12",
    "myComment": "自己的阅读短评"
  }
]
```

个人评分读取 `myRating`、`personalRating`、`userRating` 或“个人评分”，范围1–5星；未评分留空或 `null`。普通文件中的 `score`、`rating` 或“豆瓣评分”可能是站点评分，故不当作个人评分。需要采用本站规范的 `rating` 字段时，使用显式清单 `{"format":"jiashu-douban-import-v1","items":[...]}`，仍需每条完成状态或用户对缺失状态的明确确认。

## 导入作品资料

JSON 每条记录可增加 `details` 对象；CSV 可将同一对象作为经过 CSV 引号转义的 JSON `details` 列。详情只接受白名单字段，不保存原始 HTML。提供 `details` 时，以该对象为作品资料，不再混用顶层旧插件字段。空详情省略；未知字段、脚本标记、错误类型或超长内容会拒绝整个预览。

```json
{
  "title": "我的书籍记录",
  "url": "https://book.douban.com/subject/2345678/",
  "state": "读过",
  "myRating": 5,
  "details": {
    "authors": ["合成作者"],
    "publisher": "合成出版社",
    "publicationDate": "2001-09",
    "isbn": "9780000000001",
    "pages": 321,
    "summary": "作品内容简介",
    "doubanRating": 8.8,
    "ratingCount": 1234
  }
}
```

通用详情支持 `summary`、`alternateTitles`、`year`、`genres`、`countries`、`languages`、`doubanRating`、`ratingCount`。影视支持 `directors`、`writers`、`cast`、`releaseDates`、`duration`、`episodes`、`seasons`、`episodeDuration`；书籍支持 `authors`、`translators`、`publisher`、`publicationDate`、`isbn`、`binding`、`price`、`seriesTitle`、`pages`；音乐支持 `artists`、`albumType`、`medium`、`label`、`releaseDate`、`tracks`。人名、类型和曲目等复数字段使用文字数组；单项文字不超过相应字段限制。单条详情 JSON 最多 16 KiB，简介最多 12,000 字符。个人标签 `tags`、`myTags` 本版不导入。

普通 Obsidian／CSV／JSON 旧字段也按来源明确映射：`score` 为豆瓣平均分（0–10），与 `myRating` 的个人星级独立；`desc` 为作品简介，与个人短评独立。影视 `director`、`actor`、`author` 分别表示导演、演员、编剧；书籍 `author`、`translator`、`publisher`、`isbn`、`totalPage` 表示作者、译者、出版社、ISBN、页数；音乐 `actor`、`publisher` 表示表演者、唱片公司。`datePublished` 按来源进入上映日期、出版日期或发行日期，不替代收藏日期。人名列表兼容数组、简单扁平 YAML 列表及插件常见的“甲 / 乙”分隔格式，保留 `AC/DC` 这类姓名／组合名内部的斜线。

保存的 HTML 仍须为已完成收藏列表。只有每条记录内明确标记的结构化作者、出版社、ISBN、导演、演员、简介或站点评分才会成为详情；合并在一行的作者／出版信息不猜测拆分。单个作品详情页不能代替已完成状态证明。

完整备份仍为 31 张业务表，作品详情随 `douban_items.details_json` 导出。旧备份缺少该列时按空详情兼容。恢复不会用旧文件缺失的详情擦去已有丰富资料；存在不同的已填写内容时会要求处理冲突，预览后作品详情变化也会使原恢复确认失效。

标记日期读取 `markedDate`、`myCollectionDate`、`collectionDate` 或“标记日期”，不拿出版日期或文件创建时间代替。评分、标记日期和短评可以未知；不把未知填成0。所有条目链接需为豆瓣电影、书籍或音乐条目的规范链接。

同一来源主页中按“来源域＋条目ID”去重。相同条目内容完全相同会合并；不同文件给出冲突评分、短评或其他内容时，会要求先保留正确的一份再预览，避免静默覆盖。

## 清空已有资料后重新导入或同步

书影音页的“清空我的全部书影音记录”用于删除当前网站账户已保存的全部书影音，与导入表单的“清空本次资料”不同。先点击“查看清空范围”，核对分类数量，再明确点击“确认清空全部书影音记录”。范围包括全部来源主页的浏览器同步、公开同步、RSS 和文件导入资料，不受当前列表筛选影响；已绑定的豆瓣主页保留，豆瓣原站收藏和其他网站账户不受影响。

清空确认后，旧导入预览、旧待确认提交及旧同步进度失效，重试旧导入不会恢复已清空的记录。仍需导入原文件时，重新预览并确认；尚留本页的原文件不会因此上传或删除。清空结果不明时应点击“重试原清空提交”核对原回执，不重新发起另一轮清空。

也可在清空成功后，通过保留的绑定主页点击“通过浏览器同步”重新读取收藏。已安装 1.0.2 版扩展无需为清空功能升级或重新安装，刷新本站即可；清空不会自动启动同步。
