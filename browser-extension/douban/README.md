# Jiashu OS 豆瓣同步助手

这是供桌面 Chrome / Edge 使用的本机扩展。豆瓣的登录 Cookie 由浏览器正常保存；扩展不读取 Cookie 原文、不索取豆瓣密码，也不把登录凭据上传到 Jiashu OS。

## 首次安装

1. 从 Jiashu OS 的书影音页下载扩展 ZIP，解压到一个准备长期保留的文件夹。
2. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`，启用“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 manifest.json 的文件夹。请保留这个文件夹，浏览器以后会继续从这里加载扩展。
4. 在同一个 Chrome / Edge 中打开 Jiashu OS 的“书影音”，填写并保存自己的豆瓣主页，点击“连接扩展”。内置浏览器、无此扩展的其他浏览器和手机不支持此连接方式。
5. 点击“登录豆瓣”，在豆瓣自己的网页完成登录。需要验证时也在豆瓣页面自行完成，然后回本站点击“通过浏览器同步”。

## 更新扩展

1. 从本站重新下载 ZIP，解压并用新文件覆盖原来的扩展文件夹。
2. 在 Chrome／Edge 的扩展管理页点击该扩展的“重新加载／刷新”按钮，确认版本为 1.0.5 或更新。
3. 刷新本站书影音页面，点击“检测浏览器连接”确认显示新版，再开始同步。

网站发布更新不会自动替换本机已解压的扩展文件，需要同时更新并重新加载扩展。

## 后续同步

在安装了扩展的浏览器中打开本站，点击“通过浏览器同步”。扩展从本机网络读取绑定主页的已完成影视、书籍和音乐收藏，每页之间有间隔；每页整理后的条目由本站当前登录账户保存。1.0.5 起可选择只同步影视、书籍或音乐；网站先保存全部所选类别的基础收藏，再读取待分类影视和缺封面作品的详情，识别电影／电视剧并补齐可用封面。取消“基础收藏同步完成后继续补全”后，基础收藏保存完即停止，可点击“补全已同步作品”手动继续。旧扩展只支持全部类别，选择部分类别时网站会要求更新，不会悄悄读取其他类别。每次最多推进 200 个读取步骤，收藏页与单部作品详情各计一步；可随时暂停，继续时保留当前进度。浏览器登录过期或豆瓣限制访问时会说明原因，不把部分结果当成历史全量。

## 补全作品详情

1.0.3 起，在收藏列表点击“补全本页作品详情”，可沿用本机正常登录状态逐条读取已保存作品的详情。影视可补全导演、编剧、演员、片长及集数；图书可补全作者、译者、出版社、出版日期、页数和 ISBN；音乐可补全表演者、发行信息和曲目。三类作品均可补全可用的简介、豆瓣评分及评分人数等资料，缺失值会保留为空。

1.0.4 起基础同步会自动补全待分类影视和缺封面的作品，无需逐页手动分类。其他作品的完整资料仍可通过“补全本页作品详情”按需获取。收藏页和作品详情每次读取之间至少间隔 1.5 秒，可暂停；请求只含固定类型及条目 ID，不向豆瓣发送个人评分、短评或本站账户信息。遇登录、验证、访问限制或限流时停止本批读取，已保存资料保留。豆瓣评分采用十分制，个人评分仍是本人给出的五颗星。

手动作品详情读取需扩展 1.0.3，自动分类与封面补全需 1.0.4。旧扩展仍可同步基础收藏，但不会被报告为分类已完成；更新并重新加载后，显式重新同步即可补齐已有记录，不会重复创建同一来源条目。详情页和收藏页都只在电影、图书和音乐三个原有来源读取，不增加 Cookie 或持久存储权限。

扩展需要 tabs / scripting 权限以及豆瓣电影、图书、音乐三个固定站点的访问权限，供它打开普通收藏页面并读取内容。仅指定的 Jiashu OS 生产站点的书影音页能发送同步命令；其他网站无法调用此扩展。所有 Cookie 仍按浏览器和豆瓣自己的登录策略管理，退出豆瓣、清除 Cookie 或会话过期后，需要重新登录。

暂停或重新加载网页后，已经保存的记录保留。扩展后台重新启动时，本次未保存的页可能需要重新读取；网站会核对重复记录，不因重读新建相同收藏。网络回执不明时，页面会要求核对原提交，避免跳页或重复操作。

## 隐私与移除

扩展只向发起操作的本站页面返回规范化条目及进度，不返回原网页、Cookie、密码或验证页面。原始记录只在本机当前操作的内存中处理，不写入扩展持久存储。本站依然按自己的登录账户隔离已保存资料。

不再使用时，可从浏览器扩展管理页移除本扩展，并在豆瓣自行退出登录。移除扩展不会删除本站已保存的书影音记录。

1.0.5 将浏览器读取与文件导入来源分开。重新同步能反映豆瓣端明确撤销的个人评分或清空的短评；文件中没有提供的字段仍按原导入规则保留。旧版本继续兼容基础同步，但请更新至 1.0.5 以使用新的来源和类别选择。
